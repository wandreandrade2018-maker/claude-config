    Módulo: logging_config.py¶

    Logging centralizado com rotação de arquivos e múltiplos loggers.

    Funções Principais¶

    def get_logger(name: str = 'jarvisos') -> logging.Logger
def log_trade_event(event_type: str, details: dict) -> None
def log_alert(alert_type: str, message: str, severity: str = 'WARNING') -> None
def log_system_event(event_type: str, details: str) -> None

    Uso¶

    from logging_config import get_logger, log_alert, log_trade_event

logger = get_logger('meu_modulo')
logger.info('Iniciando analise')
logger.warning('Atencao: drawdown alto')
logger.error('Erro na conexao OKX')

# Alertas estruturados
log_alert('TRAILING_STOP', 'Stop loss muito proximo', 'WARNING')
log_alert('RISK', 'Drawdown > 5%', 'ERROR')

# Eventos de trade
log_trade_event('TRADE_OPEN', {'symbol': 'BTC-USDT', 'side': 'BUY', 'size': 0.1})

    Loggers Disponíveis¶

    Logger Uso Nível Padrão
    jarvisos Geral INFO
    jarvisos.trades Eventos de trade INFO
    jarvisos.alerts Alertas WARNING
    jarvisos.system Eventos do sistema INFO

    Configuração (config.yaml)¶

    logging:
  level: "INFO"
  file: "logs/jarvisos.log"
  format: "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
  max_bytes: 10485760
  backup_count: 5

    Formato de Saída¶

    2026-08-23 01:21:34,589 - jarvisos.proactive_alerts - INFO - Gerando alertas proativos
2026-08-23 01:21:34,590 - jarvisos.alerts - WARNING - TRADING: ALERTA: taxa de acerto baixa (0%)
2026-08-23 01:21:34,590 - jarvisos.proactive_alerts - INFO - Fora do horario de mercado padrao (9h-17h)

    Rotação de Arquivos¶

    • Arquivo principal: logs/jarvisos.log
    • Rotação: 10MB por arquivo
    • Backup: 5 arquivos (.1, .2, etc.)
    • Encoding: UTF-8
