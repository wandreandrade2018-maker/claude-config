    Knowledge Base / Memória de Longo Prazo¶

    Sistema de aprendizado persistente com busca semântica.

    Como Funciona¶

    Aprendizados são salvos em data/aprendizados.md no formato:

    2026-08-23 01:21:34 | Trading: O filtro ATR funciona melhor acima de 1.2
2026-08-23 01:21:34 | Estrategia: Testar trailing stop melhora resultados em laterais
2026-08-23 01:21:34 | Gestao de Risco: Evitar operacao apos 3 perdas consecutivas
2026-08-23 01:21:34 | Horario: Melhor hora e operar US500 e 14h-16h

    Salvar Aprendizados¶

    Via Script (Fechamento do Dia)¶

    python fechamento_dia.py "Concluido backtest" "Backtest US500" "ATR > 1.2 funciona"

    Via Código¶

    from trading_utils import save_learning

save_learning("ATR > 1.2 funciona melhor", "Trading")
save_learning("Trailing stop 2% ideal para BTC", "Estrategia")
save_learning("Evitar operar apos 3 perdas", "Gestao de Risco")

    Via Inbox (Captura Rápida)¶

    python captura_universal.py "ATR > 1.2 funciona" Voz aprendizado

    Consultar Conhecimento¶

    Via Script (Assistente Trading)¶

    python -c "from assistente_trading import query_knowledge; print(query_knowledge('trailing'))"

    Via Código¶

    from trading_utils import query_knowledge

print(query_knowledge("trailing"))
print(query_knowledge("ATR"))
print(query_knowledge("risco"))

    Saída: 

    Encontrado 2 registro(s) sobre "trailing":
- 2026-08-23 01:21:34 | Estrategia: Testar trailing stop melhora resultados em laterais
- 2026-08-22 21:33:33 | Estrategia: Testar trailing stop melhora resultados em laterais

    Categorias Padrão¶

    Categoria Uso
    Trading Insights gerais de trading
    Estrategia Configurações de estratégia
    Gestao de Risco Regras de risco/position sizing
    Horario Melhores horários/horas
    Psicologia Controle emocional
    Technical Analysis Indicadores/padrões

    Busca¶

    • Busca parcial (substring) case-insensitive
    • Retorna até 5 resultados mais recentes
    • Busca em: categoria + conteúdo + timestamp

    Integração Automática¶

    O Assistente Trading consulta automaticamente a base: - Ao gerar relatórios - Ao detectar padrões recorrentes - Em alertas proativos

    Arquivo de Dados¶

    Local: C:\Users\dre_l\.claude\data\aprendizados.md

    Formato: TIMESTAMP | CATEGORIA: CONTEUDO

    Boas Práticas¶

    1. Seja específico: "Trailing 2% BTC 15m" > "Trailing funciona"
    2. Inclua contexto: "BTC 15m ATR 1.2" > "ATR 1.2"
    3. Use categorias: Facilita busca posterior
    4. Registre falhas também: "Stop loss 1% falhou em range" é valioso
    5. Revise semanalmente: python revisao_semanal.py mostra aprendizados da semana
