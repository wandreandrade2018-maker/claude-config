    Scripts Principais¶

    Referência rápida de todos os scripts do JarvisOS Trading.

    Scripts de Análise¶

    Script Descrição Uso
    assistente_trading.py Relatório completo de trading + OKX python assistente_trading.py
    monitor_trailing_stop.py Monitor de trailing stop python monitor_trailing_stop.py
    analyze_sessions.py Análise por horário/sessão python analyze_sessions.py
    proactive_alerts.py Alertas proativos + logging python proactive_alerts.py
    comparative_performance.py Comparativo semanal python comparative_performance.py

    Scripts de Rotina¶

    Script Descrição Uso
    caixa_da_manha.py Resumo matinal (pendências, prioridades) python caixa_da_manha.py
    fechamento_dia.py Fechamento noturno python fechamento_dia.py "concluido" "tarefa"
    captura_universal.py Captura rápida inbox python captura_universal.py "texto" origem tag
    revisao_semanal.py Revisão semanal (segundas) python revisao_semanal.py

    Scripts de Risco¶

    Script Descrição Uso
    risk_calculator.py Position sizing + risk management python risk_calculator.py 10000 1 2

    Scripts de Config/Infra¶

    Script Descrição Uso
    config_loader.py Carrega config.yaml from config_loader import get_config
    logging_config.py Logging centralizado from logging_config import get_logger
    okx_client.py Cliente OKX API from okx_client import get_okx_status
    trading_reporter.py Gerador de relatórios from trading_reporter import print_daily_report
    config.yaml Configuração centralizada Editar diretamente
    config.toml Credenciais OKX Em C:\Users\dre_l\.okx\

    Exemplos de Uso Comum¶

    Análise Completa Diária¶

    python assistente_trading.py
python proactive_alerts.py

    Rotina Matinal¶

    python caixa_da_manha.py
python analyze_sessions.py

    Rotina Noturna¶

    python fechamento_dia.py "Concluido otimizacao" "Otimizacao de parametros"
python revisao_semanal.py  # Segundas-feiras

    Risk Management¶

    # Calcular position size
python risk_calculator.py 10000 1 2
# Conta: 10000, Risco: 1%, Stop: 2%
# Resultado: Position $5000, Risk $100

    Captura Rápida¶

    python captura_universal.py "Testar trailing stop" Voz estrategia
python captura_universal.py "Revisar logs" Texto manutencao

    OKX Operations¶

    # Ver subcontas
python okx_subaccounts.py default

# Ver bots
python -c "from okx_client import load_okx_profile, get_bot_grid_status; p=load_okx_profile(); print(get_bot_grid_status(p))"

# Ver saldo
python -c "from okx_client import load_okx_profile, get_account_balance; p=load_okx_profile(); print(get_account_balance(p))"
